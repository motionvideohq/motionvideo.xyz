## Usage

The dropzone picks and checks files; uploading them is up to you. Pass `busy` while an upload runs and `failed` if it fails.

```tsx
import { Dropzone } from "@/components/ui/magnetic-dropzone";

<Dropzone
  accept="image/*"
  maxSize={5 * 1024 * 1024}
  busy={uploading}
  failed={Boolean(error)}
  onFilesChange={(files) => upload(files[0])}
  helper="PNG or JPG, up to 5 MB"
/>;
```

## Props

| Prop | Type | Default |  |
| --- | --- | --- | --- |
| `accept` | `string` | Images, documents, media and archives | Accepted types, as for `<input type="file">` |
| `maxSize` | `number` | `1048576` (1 MB) | Largest file, in bytes |
| `multiple` | `boolean` | `false` | Allow several files |
| `value` | `string` |  | URL of a stored file, shown until a new one is picked |
| `required` | `boolean` | `false` | Hide the remove action |
| `busy` | `boolean` | `false` | Show the upload in progress and disable the actions |
| `failed` | `boolean` | `false` | Show a failed upload instead of success |
| `onFilesChange` | `(files: File[]) => void` |  | Called with the accepted files, or `[]` when removed |
| `icon` | `ReactNode` | A file-upload icon | Icon in the empty state |
| `helper` | `ReactNode` |  | Guidance inside the empty box, such as formats and size |
| `animated` | `boolean` | `true` | The magnet pull and transitions; off for reduced motion either way |
| `className` | `string` |  |  |
