Use [Button](/design/components/button) when an interface needs a clear action, and [Virtual Masonry](/design/components/virtual-masonry) when a growing collection needs a responsive, virtualized layout. Open a component to explore its live examples and API before bringing it into your app.

## Install from the registry

The shadcn CLI copies each component into your project rather than hiding it in a package. Start with Button:

```bash
npx shadcn@latest add https://motionvideo.xyz/r/button.json
```

For a virtualized masonry layout, install Virtual Masonry:

```bash
npx shadcn@latest add https://motionvideo.xyz/r/virtual-masonry.json
```

Keep the generated source in your own components folder and adapt it to your app. Each component page includes its requirements and usage examples.
