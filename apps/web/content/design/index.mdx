The system starts with [brand assets](/design/brand) for a recognizable identity and [components](/design/components) you can bring into your own app. Its foundations work together: [colors](/design/colors) establish contrast, [typography](/design/typography) gives content a clear hierarchy, [materials](/design/materials) distinguish surfaces, and [motion](/design/motion) makes changes understandable.

## Built here. Yours to build with.

React components from MotionVideo, ready for your app. Each installs with the shadcn CLI into your own components folder, so the code is yours to change.

```bash title="Install a component"
npx shadcn@latest add https://motionvideo.xyz/r/button.json
```

Explore the [component catalog](/design/components) for previews, installation commands, and examples.

Building with the system? Read the [agent-facing design guide](/design.md) for the foundations, brand downloads, component installation, and integration guidance in one place.
