## One page per video

Every video now lives at one address, `/videos/<name>`, wherever you open it from. Old links redirect there, and closing a video takes you back to the grid you came from.

## Creator pages

[Creators](/creators) lists everyone in the gallery, and each creator has a page with their videos, a link to follow them on X and a "Surprise me" button.

## Docs for agents

- Every docs page is available as Markdown by adding `.md` to its address, and pricing as `/pricing.md`. `/llms-full.txt` puts all the docs in one file.
- Open any docs page in v0, Cursor, ChatGPT, Claude, Perplexity, Gemini, Grok, T3 Chat or Scira.

## Video details

The prompt or skill now comes first, folded to six lines. Below it, "Use the template" appears when a template exists, next to "Customize this prompt".

## Command menu

The command menu opens with a "Go to" list, including "Surprise me" for a random video, and an Agents section with the MCP, the skill and `llms.txt`.
